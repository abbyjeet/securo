# Overview Skill

## Objective
Provide a high-level understanding of Securo's mission, stack, and key features. Use this skill when asked about the project's purpose, technology choices, or main capabilities.

## When to use
- "What is Securo?"
- "What tech does it run on?"
- "What features does Securo have?"
- "How do I get started with Securo?"

## Knowledge boundaries
This skill covers:
- Mission statement and value proposition (privacy-first, self-hosted finance)
- Technology stack summary
- High-level feature list (bank sync providers, multi-currency, budgets, AI agents)
- Quick-start instructions (curl install.sh or docker compose)

Do NOT dive into specific implementation details. For those, use the `structure`, `commands`, `coding-standards`, or `where-to-look` skills.

## Response pattern
Start with a concise one-sentence summary of what Securo is. Then list the stack as a table. Then bullet the major features. Keep it scannable — agents often need this info in 30 seconds or less while scanning an issue or PR description.
